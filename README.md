# 81 Votos

**[81votos.com.br](https://81votos.com.br)** — onde cada um dos 81 senadores está na eleição para a Presidência do Senado (1º de fevereiro de 2027).

- Só entra no placar o que o próprio senador disse em público, com fonte e data.
- Orientação de partido aparece separada e não conta como voto individual.
- Os dados ficam em [`data.json`](data.json) e são atualizados de hora em hora. O histórico de commits deste repositório é o registro público de cada mudança, com data e hora.

Viu um erro ou uma declaração que falta? Escreva para contato@81votos.com.br com o link da fonte.

Painel independente, sem vínculo com o Senado, partidos ou candidaturas.
